Privacy policy

rclone Drive access, a personal single-user app. Effective November 9, 2026.

This OAuth client is used only by its owner (GitHub user davinci254254) to access the owner's own Google Drive with rclone on the owner's own computer. It is not offered to anyone else.

What data is accessed

With the owner's consent, the app uses the Google Drive read-only scope (https://www.googleapis.com/auth/drive.readonly) to list the owner's Drive files and their metadata and to download file contents.

How it is used

Files are listed or downloaded only when the owner runs rclone, and only to the owner's own computer, so the owner can work with their own files there. The app cannot create, change or delete anything in Google Drive.

Storage

OAuth tokens and any downloaded files are stored only on the owner's computer. The app has no server or database of its own and collects no analytics.

Sharing

No Google user data is sold, sent to the app's developer, or shared with third parties by this app. The owner may choose to use tools on their own computer, including AI assistants, to work with their own downloaded files.

Google API Services User Data Policy

Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions. Deleting the local rclone configuration removes the stored tokens.

Contact

Questions: contact the owner through their GitHub profile, github.com/davinci254254.
