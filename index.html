rclone Drive access

A personal, single-user Google OAuth app

This page belongs to a private OAuth client that its owner (GitHub user davinci254254) uses to reach their own Google Drive from their own computer with rclone, an open-source command-line tool for cloud storage.

It is not a public service. It has no other users, nothing to sign up for, and no server of its own. All access happens directly between the owner's computer and Google.

It requests read-only Drive access (drive.readonly), so it can list and download files but cannot change or delete anything.
